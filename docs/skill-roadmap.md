# わざの道のり

`feature/beta-onboarding-profile` から作成した `feature/skill-roadmap` で、技一覧をロードマップに変更しています。これまでのローカルの初心者・プロフィール・クラブ・練習会・コメント機能も、先行コミットで引き継いでいます。

## 画面

- `/technical` の基礎25技は、横につながるカードとして表示します。現在の基礎レベルを中央に表示し、前へ・先へ・現在地への操作と横スクロールで振り返れます。
- クリア済みだけを半透明にします。未解放の技も通常の濃さで表示し、詳細とコメントを開けます。
- 基礎25技の完了後は、スピン・ターン系、片足系、ジャンプ系、タイヤ乗り系、サドル操作系、ペア・演技系から選びます。現在選んだ目標のジャンルを開き、その技を中央に表示します。
- 技の詳細で「この技を目標にする」を押すと、APIへ保存します。再読み込み・再ログイン後も目標が保持されます。合格すると目標は解除され、次の目標を選べます。
- 技同士の線はAPIの `prerequisite_ids` を使用します。ジャンプ系は3回→5回→回数・前進・ターンの分岐になります。左右スピンやサドル前後出しのような独立した選択肢は、必須順を作りません。
- 管理者の `/test` は新しい6ジャンルと、各メンバーが今受検できる技を使用します。ポイントの値はサーバーが決定します。
- 閲覧者は道のり・詳細・コメントを見られます。目標設定や検定結果の記録はできません。

基礎は従来どおりLv1〜25、基礎完了後はLv26〜の自由コースとし、自由コースの技にLv27・Lv28のような固定の進行順は表示しません。

## APIとの連携

対応するLaravel側の `feature/skill-roadmap` と合わせて利用します。

- `GET /api/skills`: `is_basic`、`is_cleared`、`is_available`、`is_current`、`locked_reason`、`prerequisite_ids`、`prerequisite_names`、`required_pair_skills`、`roadmap_order`を利用します。
- `PATCH /api/user/skill-target`: `{ "skill_id": 31 }` のように選んだ技を送信します。返却されたUserResourceを認証ストアへ反映します。
- `POST /api/challenges`: 管理者が `user_id`、`skill_id`、`success_score`を送信します。`earned_point`は送信しません。
- UserResourceの`target_skill`と`target_skill_id`をプロフィール・MemberCard・管理者検定にも反映します。

## 検証

- Reactの全49件が成功。本人の達成状態、過去の技の閲覧、未来の技の表示、6ジャンル、目標保存・失敗・再取得失敗、閲覧者、管理者検定、既存機能を確認しています。
- 本番ビルド成功。
- Chromeで本番ビルドと実際のLaravel APIを接続し、分離した確認用DBでブラウザ操作を検証します。基礎Lv24の中央表示、透明度、詳細、基礎完了、ジャンル間の目標変更、再読み込み、スマホ幅、管理者による合格とポイントを確認しています。

新しいライブラリは追加していません。
